# Breast Cancer Detection Using Machine Learning

## CodeAlpha Task 4 — Disease Prediction from Medical Data

**Name:** Sanika Rangra

**Project:** Breast Cancer Detection

## Objective

The objective of this project is to classify breast tumor samples using machine learning algorithms applied to structured medical data.

The project demonstrates an end-to-end classification workflow including data exploration, preprocessing, feature scaling, model training, evaluation, ROC analysis, and feature importance analysis.

## Dataset

The project uses the Breast Cancer dataset from scikit-learn.

Dataset dimensions:

- Samples: 569
- Original features: 30
- Target: Breast tumor classification

The dataset contains numerical features derived from diagnostic measurements.

A CSV version of the dataset used in the project is included in the `data/` directory.

## Machine Learning Workflow

The project follows these steps:

1. Dataset loading
2. Dataset exploration
3. Target distribution analysis
4. Missing-value checking
5. Train-test split
6. Feature scaling
7. Model training
8. Model comparison
9. Confusion matrix analysis
10. ROC-AUC evaluation
11. ROC curve comparison
12. Feature importance analysis
13. Saving model results

## Models Used

### 1. Support Vector Machine (SVM)

An RBF-kernel SVM was implemented using standardized features.

### 2. Logistic Regression

Logistic Regression was used as a linear classification model on standardized features.

### 3. Random Forest

Random Forest was implemented as an ensemble tree-based classification algorithm.

### 4. XGBoost

XGBoost was used as a gradient-boosting classification algorithm.

## Data Preprocessing

The dataset was divided into training and testing subsets using an 80:20 split.

Stratified splitting was used to maintain the class distribution between the training and testing sets.

StandardScaler was applied to the training and testing features for SVM and Logistic Regression.

## Evaluation Metrics

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix

ROC curves were also generated to compare the classification performance of the models.

## Feature Importance

Random Forest feature importance was calculated to examine the relative contribution of the input features.

The feature importance results are available in:

`results/breast_cancer_feature_importance.csv`

## Results

The model comparison results generated by the notebook are available in:

`results/breast_cancer_model_results.csv`

The notebook contains the complete evaluation results, including Accuracy, Precision, Recall, F1-Score, and ROC-AUC for all four models.
